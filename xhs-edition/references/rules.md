## 1. 平台硬约束

| 项 | 限制 | 落地位置 |
|---|---|---|
| 标题 | ≤20 字（含标点、emoji 均计 1 字） | `build_content` 标题候选，校验 A01 |
| 正文 | ≤1000 字（含话题标签） | 正文不复述 14 条明细，校验 A02 |
| 话题标签 | 最多 10 个 | 固定 7 个，校验 A03 |
| 图片 | 1–18 张，JPG/PNG，单张 ≤10MB，全篇统一比例 | 校验 A04/A06 |
| 图片比例 | 3:4 竖版 1080×1440 | 生成器常量 W/H，校验 A05 |
| 封面安全区 | 顶部 ≥150px / 底部 ≤1240px / 左右 ≥60px；主标题 ≥60px | 生成器 SAFE_* 常量，校验 B01/B02 |
| 站外导流 | 正文与图片不得含链接、电话、微信、邮箱、二维码及暗示跳转话术 | 校验 A07 |
| 夸大宣传 | 不使用最好 / 第一 / 100% / 保本 / 全网最等表述 | 校验 A08 |
| AI 内容标识 | 图文由 AI 生成需主动声明，发布时勾选「内容自主声明」 | 正文声明 + 封面小字 + 发布设置，校验 A09 |
| emoji | PNG 内不使用（中文字体不渲染彩色 emoji） | 校验 A10 |

## 3. 数据口径

- 报名截止取「报名 / 作品征集截止」字段。赛事整体结束日不等于报名截止。
- `eligibility` 完整保留括号内限制条件，不做去括号删减。
- 地区：中国台湾地区的赛事归入国内，表述用「中国台湾」。
- `form` 为混合或线下时标注「需现场差旅」。
- `link` 字段只用于数据审计，不进入发布物料。
- 已核验的赛事信息按原文展示，不改写、不自创营销钩子。

## 4. 校验规范

`scripts/check_xhs.py` 为独立校验器，与生成器分离。任一 FAIL 时退出码 1，结果写入 `output/check_result.json`。校验分四组：

- A 平台硬约束（10 项）
- B 版式与安全区（3 项）
- C 数据口径（5 项）
- D 工程容错，真实调用生成器函数（5 项）

图片的文字截断、重叠、豆腐块等视觉问题由人工打开图片复检，自动化校验不覆盖。
