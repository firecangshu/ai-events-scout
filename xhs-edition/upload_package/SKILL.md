# AI 赛事清单 · 小红书笔记版

## 这个 Skill 做什么

把 `data/events_data.json` 里的赛事数据，产出一篇可直接发布的小红书图文笔记：

1. `cover.png` —— 1080×1440 封面，避开信息流遮挡安全区。
2. `content_N.png` —— 1080×1440 内容页，每页 5 条，序号连续。
3. `content.md` —— 标题候选、正文、话题标签、发布设置。
4. `check_result.json` —— 逐项校验结果。

本 Skill 只做内容物料的生成与自检，不登录账号、不自动发布、不访问网络。发布动作由使用者在小红书 App 内完成。

## 何时使用

- 使用者说「把这份赛事清单发小红书」「做一版小红书物料」。
- 使用者给出赛事数据，要按小红书字数与图片规格改写。
- 使用者要检查一篇赛事笔记是否踩了导流或字数红线。

## 平台硬约束（必须遵守）

| 项 | 限制 |
|---|---|
| 标题 | ≤20 字，含标点与 emoji 均计 1 字 |
| 正文 | ≤1000 字，含话题标签 |
| 话题标签 | 最多 10 个，本 Skill 固定 7 个 |
| 图片 | 1–18 张，JPG/PNG，单张 ≤10MB，同一篇统一比例 |
| 图片比例 | 3:4 竖版 1080×1440 |
| 封面安全区 | 顶部 ≥150px、底部 ≤1240px、左右 ≥60px；主标题字号 ≥60px |
| 站外导流 | 正文与图片均不得出现链接、电话、微信、邮箱、二维码，以及暗示跳转到站外的话术 |
| 夸大宣传 | 不使用「最好 / 第一 / 100% / 保本 / 全网最」等表述 |
| AI 内容标识 | 图文由 AI 生成或润色，需主动声明；发布时勾选「内容自主声明」 |
| emoji | PNG 内不使用 emoji（中文字体不渲染彩色 emoji，会成豆腐块） |

## 数据口径

数据源 `data/events_data.json` 字段：

```json
{
  "snap": "2026-11-14",
  "today": "2026-11-14",
  "events": [
    {"name":"赛事名","scope":"国内|国外|不限","form":"线上|线下|混合",
     "eligibility":"参赛资格原文","deadline":"2026-11-15（报名截止）",
     "link":"https://...","note":"主办方与奖金信息","verified":"OK(200)"}
  ],
  "dropped": []
}
```

口径约束：

- 报名截止取「报名 / 作品征集截止」字段。赛事整体结束日不等于报名截止。
- `eligibility` 完整保留括号内的限制条件（如「需依托国内法人单位」「限合作伙伴」「须用指定平台算力」「18+」），不得删减后展示。
- 地区分「国内 / 国外 / 不限」。中国台湾地区的赛事归入国内，表述用「中国台湾」。
- `form` 为混合或线下时，图上标注「需现场差旅」。
- 正文与图片不放报名链接；`link` 字段仅供数据审计，不输出到发布物料。

## 工作流

1. 读取 `data/events_data.json`，确认 `snap` 为本次基准日。
2. 按报名截止从近到远排序，逐条计算剩余天数。
3. 运行 `scripts/gen_xhs_note.py` 生成封面、内容页与文案。
4. 运行 `scripts/check_xhs.py` 自检，全部 PASS 才交付；有 FAIL 先修再跑。
5. 人工打开图片复检文字有无截断、重叠、豆腐块。
6. 交付时附「发布设置」：勾选内容自主声明、按 cover → content_1 → content_2 顺序上传。

## 文案模板（事实型陈述）

标题候选（均 ≤20 字）：

```
2026还能报的14个AI赛事
14个AI赛事报名进行中
AI赛事清单：14个报名中
```

正文结构：基准日与条数 → 图片里有什么 → 形式/资格/地区三点说明 → 以官方页面为准 → AI 生成声明。14 条赛事明细放在图片里，正文不复述，避免超出 1000 字。

话题标签固定 7 个：`#AI赛事 #人工智能比赛 #算法竞赛 #AI黑客松 #大模型 #具身智能 #Kaggle`

文案以数据字段与官方口径为准，不自创营销钩子、不改写已核验的赛事信息。

## 校验器检查项

`check_xhs.py` 逐项输出 PASS/FAIL，并在有 FAIL 时返回退出码 1：

- A 组：标题字数、正文含话题字数、标签数、图片数量/尺寸/体积、导流词、极限词、AI 标识、emoji。
- B 组：封面安全区常量、主标题字号、页数与条数匹配。
- C 组：地区口径、资格字段完整回显、序号连续、截止字段齐全。
- D 组：空数据、缺字段、两位数序号、today 与 snap 同步的真实调用容错测试。

## 可选：本地脚本

```bash
python scripts/gen_xhs_note.py --data data/events_data.json --out output --snap 2026-11-14
python scripts/check_xhs.py --out output --snap 2026-11-14
```

脚本依赖 Python 3 与 Pillow，仅在本地读取 JSON、写 PNG 与 Markdown。中文字体从系统字体列表查找，找不到时直接报错，不以默认字体代替。

若上传环境只接受 Markdown 文件、过滤脚本，本 Skill 仍可按「平台硬约束 + 数据口径 + 文案模板 + 工作流」由智能体手工完成，图片生成部分需另行处理。
